Two threads run as shown, then main joins both and prints r1 and r2. Which statements are true? Select all that apply. Select all that apply
Why. This is the store buffering test. With relaxed (and even with release and acquire), each thread's load may be satisfied before its own store becomes visible to the other thread, so both can read 0; store buffers on real CPUs, x86 included, do exactly this. Release and acquire only order accesses around a load that reads from a release store, and here no load reads the other thread's store, so they do not help. Only sequential consistency puts all four operations in one total order, where whichever store comes first must be seen by the other thread's later load. (1, 1), (0, 1) and (1, 0) are all possible. Atomics never race, so the values are always 0 or 1.

Why. Since C++11, initialization of a function local static is thread safe ("magic statics"): exactly one thread runs the constructor and the others wait until it finishes, so ctor prints once.
