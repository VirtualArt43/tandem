Why. joinable() describes association, not whether instructions are still executing. Completion does not discharge ownership, and the callable's return value is ignored, so it cannot change joinability.

For an owning std::unique_lock, how does release() differ from unlock()?
Why. release() returns the mutex pointer, clears the association and leaves the mutex held. unlock() unlocks it and clears ownership while preserving association. Neither operation keeps the wrapper owning, so they are not aliases.
